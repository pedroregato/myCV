◈ Visão Geral

O myCV é uma plataforma pessoal de gestão de carreira construída em Python. Vai além de gerar um PDF — é o sistema central que mantém o histórico profissional de Pedro Gentil estruturado, versionado e pronto para ser usado em qualquer canal: currículo em PDF (PT/EN), perfil LinkedIn, posts e projetos.

📄 Geração de CV Ativo

Gera PDFs profissionais em PT e EN a partir de dados YAML. Layout com barra lateral, foto, destaques de impacto e depoimentos.

🤖 Assistente IA Ativo

Usa a API do Claude (Anthropic) para reescrever bullets, revisar seções, traduzir conteúdo e gerar rascunhos de posts.

🔗 LinkedIn Em breve

Seções do perfil salvas como referência. Publicação assistida por IA via LinkedIn API está no roadmap.

Princípio central

Dados ficam em data/, código fica em src/.
Para atualizar o CV, edite os arquivos YAML — não o código Python. A IA ajuda a formular o texto; você decide o que entra.

⚙ Configuração

Pré-requisitos

  • Python 3.10+
  • Virtualenv ativo: .venv/
  • Chave de API da Anthropic (para funcionalidades de IA)

Instalação

# 1. Ativar o ambiente virtual
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux/Mac

# 2. Instalar dependências
pip install -r requirements.txt

# 3. Configurar a chave da API
# Copie o arquivo de exemplo e preencha com sua chave
copy .env.example .env          # Windows
cp .env.example .env            # Linux/Mac
# Depois abra .env e adicione: ANTHROPIC_API_KEY=sk-ant-...
Atenção: O arquivo .env nunca deve ser commitado no git. Ele já está no .gitignore. Sua chave fica apenas na sua máquina.

📄 Gerar PDFs

Os PDFs são gerados a partir dos arquivos data/profile_pt.yaml e data/profile_en.yaml. O resultado vai para a pasta output/.

# Gerar ambas as versões (PT e EN)
python scripts/generate_cv.py

# Gerar apenas Português
python scripts/generate_cv.py --lang pt

# Gerar apenas Inglês
python scripts/generate_cv.py --lang en

# Compatibilidade com o arquivo legado
python gerar_curriculo.py
Saída:
output/Curriculo_Pedro_Gentil.pdf — versão em Português
output/Resume_Pedro_Gentil.pdf — versão em Inglês

Toda atualização de conteúdo é feita nos arquivos YAML. Nunca edite o código Python para mudar texto.

Como adicionar um novo destaque de impacto

Abra data/profile_pt.yaml e adicione um item à lista destaques:

destaques:
  # itens existentes...
  - "NOVO: Descrição do resultado com métrica quantificada (projeto X)."

Como adicionar uma nova experiência

experiencia:
  - empresa: "NOME DA EMPRESA"
    periodo: "2024 - Atual"
    cargo: "Título do Cargo"
    detalhes:
      - "Bullet 1 com verbo de ação e resultado."
      - "Bullet 2 com contexto e impacto."
Dica: Use o comando python scripts/update_with_ai.py bullet para que o Claude sugira o texto do bullet antes de você escrever manualmente.

📦 Criar Snapshot (Histórico)

Antes de qualquer atualização significativa, crie um snapshot para preservar a versão atual.

# Criar snapshot com descrição
python scripts/snapshot.py --message "Adicionei projeto X na seção destaques"

# Atalho -m
python scripts/snapshot.py -m "Antes de atualizar experiência FGV"

O script cria uma pasta data/history/vN_YYYY-MM-DD/ com os dois YAMLs e registra a entrada no changelog.md.

Ver histórico

# Abrir o changelog
data/history/changelog.md

# Comparar duas versões (usando diff)
diff data/history/v1_2026-04-26/profile_pt.yaml data/profile_pt.yaml
Boa prática: Sempre crie um snapshot antes de editar os YAMLs. O fluxo recomendado é: snapshot → editar YAML → gerar PDF → verificar.

🤖 Assistente IA — Como Funciona

O assistente usa o modelo claude-sonnet-4-6 via API da Anthropic. Ele não altera os arquivos automaticamente — sugere texto e você decide o que entra.

O que a IA faz
  • Reescreve descrições informais como bullets profissionais
  • Traduz conteúdo PT → EN e EN → PT
  • Revisa seções e aponta melhorias
  • Gera rascunhos de posts para o LinkedIn
  • Sugere trechos YAML prontos para colar
O que a IA não faz
  • Não edita os arquivos YAML diretamente
  • Não publica no LinkedIn sem sua aprovação
  • Não cria snapshots automaticamente
  • Não tem acesso ao seu histórico entre sessões
Custo: Cada chamada à API consome tokens. Revise o texto produzido antes de fazer chamadas repetidas sobre o mesmo conteúdo.

⌨ Comandos CLI do Assistente

Todos os comandos são executados via python scripts/update_with_ai.py <comando>.

bullet — Reescrever uma descrição como bullet

python scripts/update_with_ai.py bullet

Modo interativo: você descreve o que aconteceu informalmente e o Claude devolve um bullet orientado a resultado.

review — Revisar uma seção do CV

python scripts/update_with_ai.py review --section resumo_texto --lang pt
python scripts/update_with_ai.py review --section destaques --lang en

translate — Traduzir uma seção entre PT e EN

# Traduzir seção do PT para EN
python scripts/update_with_ai.py translate --section resumo_texto --from-lang pt

# Traduzir seção do EN para PT
python scripts/update_with_ai.py translate --section destaques --from-lang en

yaml-update — Sugerir YAML para nova entrada

python scripts/update_with_ai.py yaml-update --section destaques
python scripts/update_with_ai.py yaml-update --section experiencia
python scripts/update_with_ai.py yaml-update --section publicacoes

Modo interativo: você descreve o que aconteceu e o Claude devolve o bloco YAML pronto para colar no arquivo.

post — Gerar rascunho de post para o LinkedIn

# Case de resultado em Português
python scripts/update_with_ai.py post --type case --lang pt

# Post técnico em Inglês
python scripts/update_with_ai.py post --type technical --lang en

# Reflexão profissional
python scripts/update_with_ai.py post --type reflexao --lang pt
ComandoParâmetrosInterativo?
bulletnenhumSim
review--section, --langNão
translate--section, --from-langNão
yaml-update--sectionSim
post--type, --langSim

ƒ Funções Python do Assistente

Para uso programático, importe diretamente de src.ai.cv_assistant:

from src.ai.cv_assistant import (
    improve_bullet,
    translate,
    review_section,
    draft_linkedin_post,
    suggest_yaml_update,
)
improve_bullet(description: str, context: str = "experiência profissional", lang: str = "pt") → str

Recebe uma descrição informal e retorna um bullet de CV polido.

translate(text: str, target_lang: str = "en") → str

Traduz texto de CV preservando tom e estrutura. target_lang: "en" ou "pt".

review_section(section_name: str, content: str, lang: str = "pt") → str

Analisa uma seção e retorna pontos fortes, sugestões e versão revisada.

draft_linkedin_post(achievement: str, post_type: str = "case", lang: str = "pt") → str

post_type: "case" | "tecnico" | "reflexao"

suggest_yaml_update(section: str, description: str, example: str = "") → str

Retorna um bloco YAML pronto para inserir em data/profile_pt.yaml.

🕓 Sistema de Histórico

Cada snapshot salva uma cópia dos dois YAMLs em data/history/vN_YYYY-MM-DD/ e registra uma entrada no changelog.md.

Criar snapshot

python scripts/snapshot.py -m "Descrição do que mudou"

Ver o histórico

# Abrir o changelog no editor
code data/history/changelog.md

# Listar versões existentes (Windows)
dir data\history

# Comparar versão atual com v1
diff data/history/v1_2026-04-26/profile_pt.yaml data/profile_pt.yaml

Restaurar uma versão anterior

# Copiar versão v1 de volta (com cuidado — crie snapshot antes!)
python scripts/snapshot.py -m "Backup antes de restaurar v1"
copy data\history\v1_2026-04-26\profile_pt.yaml data\profile_pt.yaml
copy data\history\v1_2026-04-26\profile_en.yaml data\profile_en.yaml
Atenção: Restaurar uma versão sobrescreve os YAMLs atuais. Sempre crie um snapshot da versão corrente antes de restaurar.

📝 Guia Rápido de YAML

Alguns lembretes para editar os arquivos .yaml sem erros:

Tipos de valores

# String simples
nome: "PEDRO GENTIL REGATO DE OLIVEIRA SOARES"

# String com caracteres especiais (use aspas)
titulo: "ARQUITETO DE SOLUÇÕES | ML/NLP & GENAI"

# Texto longo (use | para preservar quebras de linha)
resumo_texto: |
  Primeiro parágrafo do texto.

  Segundo parágrafo, separado por linha em branco.

# Lista simples
idiomas:
  - "Português (Nativo)"
  - "Inglês (Avançado/Fluente)"

# Lista de objetos
experiencia:
  - empresa: "NOME DA EMPRESA"
    periodo: "2024 - Atual"
    cargo: "Título do Cargo"
    detalhes:
      - "Bullet de resultado."

Erros comuns

ErroCausaSolução
Texto cortadoAspas não fechadasVerifique que toda string tem " de abertura e fechamento
Indentação inválidaMix de tabs e espaçosUse sempre 2 espaços, nunca tab
Caractere especial :Dois pontos no meio de stringColoque a string entre aspas duplas
Validar o YAML: Execute python -c "import yaml; yaml.safe_load(open('data/profile_pt.yaml', encoding='utf-8'))" para verificar se o arquivo está bem formado antes de gerar o PDF.
